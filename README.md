
# 관리자가 컴퓨터로 확인하는 페이지


+++ 내용 다듬을 예정 
===================================
# React + TypeScript + Vite

1. 개요

본 프로젝트는 기존 베프 무인 키오스크 서비스의 운영자를 위한
관리자(Admin) 전용 웹 페이지입니다.

매출, 주문, 메뉴 현황 등 운영에 필요한 정보를
PC 환경에서 빠르고 직관적으로 확인할 수 있도록 설계되었습니다.

운영자는 짧은 시간 안에 매장의 상태를 파악해야 한다는 점에 착안하여,
운영체제(OS) 기반 관리자 인터페이스에서 영감을 받은 대시보드 구조를 적용했습니다.

2. UX · 디자인 설계 방향

본 관리자 페이지는 PC 기반 관리자 사용 환경을 전제로 설계되었습니다.

OS 환경의 관리자 화면을 참고한 구조

카드(Card) 단위로 정보를 분리하여 배치

한 화면에서 핵심 지표를 즉시 인지할 수 있도록 구성

데이터 가독성 중심 설계

차트와 텍스트 리스트를 병행 제공

수치 비교, 순위 파악, 추세 확인을 동시에 가능하도록 구성

운영 흐름을 고려한 레이아웃

관리자 작업 동선을 고려한 정보 배치

불필요한 시각 요소를 최소화하고 핵심 데이터 중심 구성

3. 페이지 구성 및 기능

📌 Dashboard

일간 매출 요약 정보 제공

시간대별 매출 현황 시각화

인기 메뉴 TOP 5 분석

도넛 차트와 메뉴 리스트를 병행 구성하여
비중과 순위를 동시에 파악 가능

📌 Order Management

주문 내역 조회

주문 금액, 결제 수단, 주문 상태 정보 제공

실시간 주문 데이터 기반 렌더링

📌 Menu Management

메뉴 목록 조회

카테고리 기반 데이터 처리

관리자 관점에서 메뉴 구조를 한눈에 확인 가능

5. 구현 포인트

관리자 페이지 특성을 고려한 컴포넌트 단위 설계

목업 데이터가 아닌 실제 API 응답 기반 렌더링

TypeScript를 활용한

API 응답 타입 정의

데이터 구조 명확화

차트 영역과 리스트 영역을 분리하여

데이터 가독성 향상

유지보수성 강화

6. 프로젝트 구조
src/
 ├─ pages/        # Dashboard, Order 등 페이지 단위
 ├─ components/   # 공통 UI 컴포넌트
 ├─ hooks/        # 데이터 호출용 커스텀 훅
 ├─ api/          # Axios client 및 API 함수
 ├─ types/        # TypeScript 타입 정의
 └─ assets/       # 이미지 및 아이콘

7. 실행 방법
npm install
npm run dev

관리자 UX 관점에서 데이터 가독성과 구조 설계에 집중했습니다.
